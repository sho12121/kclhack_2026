# 掲示板のお気に入り・作成時の招待

Supabase SQL Editorで `supabase/migrations/202611060004_favorites_invitations.sql` を実行する。既存データの削除はしない。通知の種類の制約を置き換えるため警告が出る場合がある。

## お気に入り

通常アカウントで一覧・会話画面から登録／解除できる。プロフィールの「お気に入り」タブに保存済み掲示板を表示する。お気に入りは参加申込ではない。ゲストは通常ログインを案内する。本人の登録情報だけをRLSで読み取り可能にし、書き込みは権限を検証するDB関数経由。掲示板が削除されると登録も消える。

## 招待

作成画面にフォロー中の通常ユーザーを最大50人表示し、任意に選択する。確認画面でも招待先を表示する。作成と招待は一つのDBトランザクションで保存し、相手に「掲示板への招待」のアプリ内通知を届ける。メール通知は送らない。招待だけでは自動参加・席の予約・会話閲覧権限は与えない。相手が通知から開き、通常の参加操作を行う。招待されていない人も募集条件を満たせば参加可能。

DBでフォロー関係・通常アカウント・作成権限を再検証する。通信再送でも同じ掲示板・相手への招待と通知は増やさない。既存の「フォローした人が掲示板を作成」の通知とは別のイベント。

## 検証

`npm run lint` / `npm run typecheck` / `npm test` / `npm run build`。
DB権限・保存・再送・削除時の連動は `supabase/tests/favorites-invitations-security.mjs` で検証する。
PGliteを別環境に用意し、`PGLITE_MODULE` にそのエントリーポイントを渡して実行できる。
