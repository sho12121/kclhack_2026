# 掲示板のNGワードフィルター

## 有効化

Supabase SQL Editorで `supabase/migrations/202611070003_board_filter.sql` を実行する。先に返信引用の006とネタバレ表示の202611070001までを反映する。既存の掲示板・コメントは削除しない。

掲示板作成者の画面だけに「NGワードを『**』に置き換える（全員に適用）」のチェックを表示する。通常アカウント・ゲストのどちらの作成者でも操作できる。DBでも作成者以外の変更を拒否する。初期状態はオフ。

設定は掲示板ごとに保存される。切替後、表示済みの会話も新しい設定で取得し直す。ほかの参加者は通常の5秒更新で設定変更を検知する。古い会話を表示していても、切替時には最新50件を表示して、未加工の古い表示を残さない。

## 辞書

元ファイル `ng_words_movie_board.json` を直接読み込む。辞書の `mask` 指定のみ自動置換し、`review`・`monitor` は自動置換しない。NFKC・小文字化、英語のASCII単語境界、長い語の優先、allowlistの該当箇所だけの保護、mask指定の正規表現を扱う。カタカナからひらがなへの任意変換は行わない。

正規化後の位置を原文の位置に対応させ、対象の範囲だけを置き換える。通常の文章の全角表記・絵文字などは変更しない。辞書のreplacementは***だが、ユーザー指定を優先して固定の**を使う。原文はDBに保持し、オフにすると元の表示へ戻る。

## 適用先

コメント本文・返信引用・投稿直後の表示・返信通知の本文。辞書はブラウザに配布せず、アプリのサーバー側で処理する。映画名やニックネームは対象外。

これはアプリの表示フィルターであり、原文の削除や暗号化ではない。DBは原文と設定を保存し、取得関数はアプリに原文と設定を返す。アプリがブラウザ向けのHTML・API・投稿応答を返す前に置換する。既に端末に届いた内容の取り消しや、更新を停止した端末の即時書き換えはできない。通知の本文は取得・更新時の設定に従う。
