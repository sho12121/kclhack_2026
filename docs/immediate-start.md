# 今から開始する

作成画面で「今から」と「日時を指定」を選ぶ。
「今から」は日付・時刻の入力を隠し、確認画面にも固定日時ではなく「今から（作成後すぐに開始）」と表示する。確認に時間をかけても日時の期限切れにならない。

Supabase SQL Editorで `supabase/migrations/202611070002_immediate_start.sql` を実行する。先にネタバレ設定の `202611070001_board_spoilers.sql` までを反映する。既存データは変更・削除しない。

即時開始ではアプリから日時を指定せず、DB関数が作成トランザクションの現在時刻を `starts_at` に保存する。映画情報取得が長引いた場合も、古いアプリ時刻を使わない。日時指定の場合だけ未来日時の検証を維持する。

旧クライアント向けの関数はそのまま残す。ゲスト制限・招待・ネタバレ表示・再送時の作成時刻維持も継続する。

`supabase/tests/immediate-start-security.mjs` で即時投稿・日時指定の過去拒否・ゲスト・招待・再送・権限・再実行を検証する。
