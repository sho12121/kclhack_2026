# ゲスト参加設定・フォロー・通知・削除

## Supabaseへの追加設定

先に既存の `202611010001_movie_boards.sql` を適用済みのプロジェクトで、SQL Editorから `supabase/migrations/202611060001_social_features.sql` を実行します。既存データを残して列・テーブル・関数・ポリシーを追加・更新します。古い関数やポリシーの置き換えで削除操作の警告が出る場合がありますが、このSQLの適用時点では保存済みのプロフィール・掲示板・会話を削除しません。今後の削除は本人が画面で確認したときに行います。

すでにある掲示板は「ゲスト参加OK」を維持します。適用後に古い初期マイグレーションだけを再実行すると関数が旧仕様へ戻るため、マイグレーションはファイル名順で適用してください。今回の追加用SQLは再実行できます。

掲示板管理者によるコメント削除には、続けて `supabase/migrations/202611060002_board_moderation.sql` を適用します。こちらも既存データを削除せず、削除用関数の権限判定だけを更新します。

## 操作

- 掲示板作成画面で「ゲストユーザーの参加を受け入れる」を選択します。オフの場合は通常アカウントだけが参加できます。ゲスト自身が作成する場合はオンが必要です。確認画面と一覧にも参加条件を表示します。
- プロフィールは `/account` で編集・保存します。ニックネーム・自己紹介・好きなジャンル・ひとことは公開プロフィールで表示します。生年月日・性別・居住地は本人にだけ表示します。
- `/users` のニックネーム検索、掲示板の作成者、会話の投稿者から公開プロフィールを開けます。ゲストには公開プロフィールを作らず、フォロー操作は通常アカウントに限ります。
- 公開プロフィールでフォロー・解除できます。自分のプロフィールと公開プロフィールのフォロー件数から、フォロー中・フォロワー一覧を開けます。検索・一覧は最大50人です。
- 通知はサイト内の `/notifications` に届きます。「フォローされた」「フォロー先が掲示板を作成」「参加中の掲示板への新しい投稿」「参加中の掲示板が削除」の4種類です。メールやブラウザのプッシュ通知ではありません。
- ヘッダーの未読数は表示中のページで30秒ごとに確認します。通知画面の「通知を更新」で一覧を更新し、1件ずつ、またはすべて既読にできます。通知は30件ずつ過去へ読み込めます。会話本文は通知に含めません。
- 自分の投稿履歴はプロフィールで最近50件表示します。削除済みコメントは履歴から除きます。
- 会話画面または自分の投稿履歴から、自分のコメントを削除できます。本文を上書き消去し、「削除されたコメントです。」に置き換えます。投稿ID・投稿者・日時は会話の位置を保つため残します。元の本文はアプリ用DBに残しません。
- 掲示板管理者（作成者）は、その掲示板内に限り、他の参加者のコメントも「管理者としてコメントを削除」から削除できます。別の掲示板の作成者であることや、参加者であることだけでは他人のコメントを削除できません。
- 他の参加者の画面でも5秒ごとの取得で削除を反映します。新しい投稿と、表示範囲内の削除済みIDを同じDB呼び出しで取得します。
- 作成者は会話画面の「自分の掲示板を削除する」から、確認後に掲示板全体を削除できます。参加登録と会話も削除されます。参加者には削除の通知が届きます。他人の掲示板そのものは削除できません。

## DBの権限

`follows` と `notifications` はクライアントから直接追加・変更できません。認証済みの本人がDB関数を使って操作します。フォロー通知はDBのINSERTトリガーで作成するため、同じフォロー要求を再送しても重複しません。

通知はRLSで受信者本人だけに制限します。公開プロフィールは専用のDB関数で公開項目だけ返し、既存の `profiles` の本人限定RLSは維持します。

ゲスト制限と削除権限はDB関数でも検証します。画面のボタンを隠すだけではなく、APIを直接呼び出しても拒否します。`service_role` キーや新しい秘密情報は不要です。

## 主なファイル

- `src/app/boards/actions.ts`：作成・参加・投稿・本人と掲示板管理者による削除
- `src/lib/boards.ts`、`src/lib/board-messages.ts`：参加者限定の会話と削除の取得・検証
- `src/app/users/`：ユーザー検索・公開プロフィール・フォロー操作
- `src/app/notifications/`、`src/app/api/notifications/route.ts`：通知一覧・既読・未読件数
- `src/components/social/`：フォロー・通知・履歴の削除ボタンと表示
- `supabase/migrations/202611060001_social_features.sql`：DBの追加設定
