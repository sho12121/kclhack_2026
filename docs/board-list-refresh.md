# 掲示板一覧の自動更新

一覧を表示している間、15秒ごとに `/api/boards` から最新データを取得する。新規・削除された掲示板、参加人数、本人の参加・お気に入り状態を反映する。

- 画面を開いた時も取得し、先読み時点の古い一覧を更新する。
- ジャンル・開催状況・並び順は維持する。選択中ジャンルの掲示板が削除されても、選択を勝手に解除しない。
- 画面全体を再読み込みしない。作成画面では一覧コンポーネントを表示しないため定期取得もしない。
- タブが非表示の間は新しい取得を行わず、再表示時に即時取得する。
- 同時に複数の取得を走らせず、画面を離れるとタイマーと通信を終了する。
- 通信失敗・不正な応答では前の一覧を保持して案内し、次の15秒周期で再試行する。
- 応答には募集情報だけを含め、会話本文は含めない。本人の状態を含むため `Cache-Control: private, no-store` を指定する。

SQLの追加実行は不要。`tests/board-list-data.test.ts` で応答の検証を確認する。
ブラウザで更新による追加・削除・参加人数の反映、フィルター維持、失敗時の保持、タブ非表示・復帰、画面を離れた後の停止を確認済み。
