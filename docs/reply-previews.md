# 通知件数・返信本文・引用元への移動

`supabase/migrations/202611060006_reply_previews.sql` をSQL Editorで実行する。先に返信用の005までを反映する。既存データの削除はしない。

- メニューの「通知」の右上に赤い小さな未読件数を表示する。0件は非表示、100件以上は99+。件数取得は画面のデータ表示を待たせずブラウザで行い、表示中だけ30秒間隔・タブ復帰・既読操作で更新する。
- 返信通知に最大240文字の返信本文を表示し、通知から返信コメントへ直接移動する。
- 会話の返信には返信先の本文を最大240文字、2行で引用表示する。引用を押すと元コメントへ移動して強調する。
- 未読込の古いコメントも、権限を確認する専用RPCで周辺の最大50件を取得して移動する。過去の表示から「最新の会話に戻る」で最新50件へ戻れる。過去表示中も後続を通常の増分取得で追加する。
- 返信ボタンは背景のない小さな文字ボタンにする。
- 返信元が削除されたら引用も削除済み表示に変える。引用元が現在の取得範囲より古い場合も削除を同期する。
- 通知受信者が参加していない会話・ゲスト不可の会話・削除済み返信の本文は返さない。通知に本文そのものをコピー保存せず、参照元から権限確認して取得する。

`supabase/tests/reply-previews-security.mjs` で権限・本文・古い引用元・削除同期・再実行を検証する。
