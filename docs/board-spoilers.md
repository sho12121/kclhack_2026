# ネタバレ注意

作成フォームの「ネタバレ注意」ボタンで切り替える。初期状態はオフ。オンで確認・作成すると、一覧・会話画面・プロフィールの作成済み／お気に入り掲示板に赤文字・赤枠の「ネタバレ」を表示する。設定変更後は作成内容を再確認する。

Supabase SQL Editorで `supabase/migrations/202611070001_board_spoilers.sql` を実行する。先に掲示板・フォロー・招待のSQLを反映しておく。既存データは削除せず、以前の掲示板の初期値はオフ。再実行しても保存済みの設定は維持する。

- `boards.has_spoilers` に設定を保存する。
- 作成と招待・ラベル設定は一つのDBトランザクションで保存する。
- 同じ作成リクエストの再送では最初の設定を維持する。
- 一覧取得の新しいRPCは既存の公開募集情報にラベルだけを追加する。
- 一覧の15秒自動更新にもラベルを含める。

ネタバレ本文を隠す機能ではなく、入室前に注意を示すラベル。

`supabase/tests/board-spoilers-security.mjs` で保存・ゲスト・招待との併用・再送・権限・再実行を検証する。
